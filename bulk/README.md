# שמירת 90 תמונות ויותר, אחת אחרי השנייה

כלי נפרד מהמוריד הישן של Batch. בוחרים תמונות או תיקייה פעם אחת; התוכנה מעלה כל תמונה לכלי הרגיל של Photoroom, ממתינה לתוצאה ולוחצת Download. אין מגבלת מספר קבצים בקוד. קבצים מתוך תת־תיקיות נכללים גם הם.

## הפעלה ב-Mac

1. התקינו Chrome ו-Python 3.9 ומעלה, אם אינם מותקנים.
2. לחצו פעמיים על `שמירת-תיקיית-תמונות.command`. בפעם הראשונה תותקנה הספריות.
3. בחרו תיקייה או מספר תמונות בחלון הבחירה. הבחירה מתחילה את העלאתן ל-Photoroom.
4. ייפתח Chrome נפרד לצורך העבודה. התוצאות נשמרות ב-Downloads/Photoroom-Results.

אפשר להשתמש במחשב בזמן העבודה, אך אין לסגור או לשנות את לשוניות הדפדפן של התוכנה. מצב ההתקדמות מופיע בחלון ההפעלה. לעצירה: Control+C. מפעילים שוב ובוחרים את אותם המקורות להמשך. דילוג נעשה רק לאחר אימות חתימת התוצאה; מקור שערכו השתנה מקבל תוצאה חדשה. שמות כפולים מתיקיות שונות אינם מתנגשים. אין דריסת קבצים קיימים.

## בדיקה מדגמית של שלוש תמונות

```sh
.venv-bulk/bin/python bulk/runner.py "/path/to/images" --limit 3
```

הסירו את `--limit 3` כדי לעבד את כל התיקייה. אפשר להעביר `--output "/path/to/results"`, `--delay 5` או `--timeout 180`. תיקיית התוצאות מוחרגת מסריקת המקורות. הקבצים המקוריים אינם משתנים.

## מה נבדק ומה עדיין דורש בדיקה

נבדקו באתר החי תמונת הדוגמה הציבורית, העלאה דרך Start from a photo וכפתור Download. בדיקות יחידה מכסות תורים גדולים, שמות זהים, המשך עבודה, קבצים פגומים וסדר פעולות ההעלאה וההורדה. הרצה אוטומטית מלאה של 90 קבצים עדיין לא אומתה. מומלץ להתחיל ב-3 תמונות ולבדוק שקיפות ואיכות לפני הרצה מלאה.

הכלי משתמש באתר הציבורי דרך דפדפן גלוי ובכפתורים הרגילים. אם מופיעה דרישת התחברות, מגבלת שימוש, CAPTCHA או תשלום, הוא נעצר ומאפשר לבדוק את הדפדפן. אין הבטחה שהאתר יאפשר 90 הורדות ברצף. הוא לא עוקף מגבלות, לא פונה לממשקי API פנימיים ולא מפעיל מנוי. איכות ההורדה היא זו שהאתר מספק; המרה ל-PNG אינה משפרת רזולוציה.

GitHub שומר את הקוד. ההרצה והקבצים נשארים במחשב; תמונות המקור נשלחות ל-Photoroom לצורך העיבוד. יומן ההתקדמות מכיל נתיבי קבצים ונמצא רק בתיקיית הפלט. אין צורך במפתח API או בהרשאות נגישות. כל הרצה משתמשת בפרופיל זמני, ללא קריאת הפרופיל האישי של Chrome.

אם התהליך הופסק אחרי כתיבת תמונה ולפני עדכון היומן, הוא יעצור מול קובץ שאינו מאומת במקום לדרוס אותו. במקרה כזה בחרו תיקיית פלט חדשה, או בדקו והעבירו ידנית את הקובץ שעליו דווח לפני ההמשך.
