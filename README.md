# שמירת אוסף Photoroom מ-Chrome הקיים

האפליקציה שולטת בחלון Chrome שכבר פתוח ומחובר לחשבון. היא בוחרת תמונה, מפעילה Save Image As ומאמתת שנשמר קובץ PNG ב-Downloads. אין צורך לפתוח פרופיל דפדפן חדש או להפעיל חיבור ניפוי שגיאות.

## הפעלה

1. ב-Chrome פתחו את האוסף בכתובת app.photoroom.com/batch.
2. פתחו תמונה במצב מוגדל, עם פס תמונות ממוזערות בתחתית, כפי שהוצג בזמן בניית האפליקציה. השאירו את ממשק Chrome באנגלית.
3. לחצו פעמיים על `הפעלה.command`. בהרצה הראשונה יותקנו ספריות Python בסביבה נפרדת.
4. הזינו שם לאוסף (לדוגמה walking-01). לכל אוסף חדש תנו שם חדש. להמשך אותה הורדה השתמשו באותו שם.
5. עברו לחלון Chrome בתוך שבע שניות. השאירו אותו בחזית ואל תשתמשו במקלדת ובעכבר בזמן ההורדה.
6. בסיום יופיע מספר התמונות שנשמרו. ודאו שהוא תואם למספר התמונות שבאוסף באתר.

אם מופיעה הודעה על נגישות: פתחו הגדרות מערכת ← פרטיות ואבטחה ← נגישות, ואפשרו Terminal. אם צריך, הוסיפו את Terminal מתוך Applications/Utilities. זו הרשאה לשליטה בחלונות, הדרושה ללחיצות ולמילוי חלון השמירה. האפליקציה אינה מעניקה אותה בעצמה. לאחר מכן הפעילו שוב.

## עצירה והמשך

לעצירה עברו לחלון אחר, או העבירו את העכבר לפינה השמאלית העליונה של המסך הראשי. אפשר גם לחזור ל-Terminal וללחוץ Control+C. העצירה נבדקת בין פעולות. קבצים שכבר נשמרו אינם נמחקים.

קבצים נשמרים ישירות ב-Downloads עם קידומת photoroom ושם האוסף. קובץ progress.json שומר את ההתקדמות וחתימת כל קובץ. בהרצה חוזרת עם אותו שם האפליקציה מדלגת רק על קבצים ששמירתם אומתה. אין למחוק את היומן אם רוצים להמשיך. אם תמונות האוסף השתנו או נערכו, יש להשתמש בשם הרצה חדש. אם התהליך הופסק בין שמירת תמונה לעדכון היומן, האפליקציה נעצרת מול קובץ קיים במקום לדרוס אותו.

## מגבלות ידועות

- נשמרת התמונה שהדפדפן מציע ב-Save Image As. בבדיקת האוסף נשמר PNG בגודל 1276×718, לעומת כיתוב מקור של 1920×1080. זה אינו מבטיח ייצוא מקורי או רזולוציה מלאה. מידות כל קובץ נרשמות ביומן.
- האפליקציה מותאמת לממשק Photoroom שנבדק ולפס התמונות האופקי. היא גוללת לתחילת הפס, מעבדת את התמונות וגוללת לחשיפת נוספות. זיהוי סוף האוסף מבוסס על מספר ניסיונות גלילה ללא שינוי, ולכן יש להשוות את הספירה לאוסף. שינוי מבנה האתר עשוי לחייב התאמה.
- נדרשים שמות תמונות ייחודיים באוסף. אין לשנות את האוסף תוך כדי ההורדה.
- לא נעשה שינוי ברקע, בעריכות או במנוי. לא נלחץ כפתור Pro.
- כאשר טעינת התמונה איטית, אפשר להגדיל את ההמתנה עם `--settle 5`.
- macOS, Chrome באנגלית ו-Python 3.9 ומעלה נדרשים.

## אפשרויות נוספות

```sh
.venv/bin/python downloader.py --session walking-01 --limit 1
.venv/bin/python downloader.py --session walking-01 --settle 5
.venv/bin/python downloader.py --inspect
```
